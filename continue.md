# Project Continuation Guide: Bare-Metal MIPS on Nationalchip SoC

## 1. Project Overview & Objective
Write, compile, and execute custom bare-metal MIPS assembly code on a Nationalchip set-top box, progressing from basic execution to serial console (UART) text output.

## 2. Hardware & Environment Specs
* **SoC:** Nationalchip MIPS 32-bit Little-Endian (Chip ID: `5874`).
* **Toolchain:** WSL running MIPS cross-compiler (`mipsel-linux-gnu-*`).
* **Bootloader:** U-Boot (loads binaries via USB FAT32).
* **RAM Base:** `0x80000000` (cached / `kseg0`) and `0xa0000000` (uncached / `kseg1`).

---

## 3. Current Progress & Accomplishments
* **Linker Script Fixed:** Overcame massive 4MB binary padding issues caused by default linker scripts by implementing a custom flat-binary linker script (`link.ld`), successfully shrinking output binaries to under 100 clean bytes.
* **Execution Verification:** U-Boot successfully loads and hands over execution via `go 0x80008000` (or `0xa0008000`), running infinite loops cleanly without exceptions.

---

## 4. Current Obstacle / Roadmap
* **Roadblock:** Direct Memory-Mapped I/O (MMIO) character writes via `sb` to common MIPS UART base addresses (`0xb8000000`, `0xb8100000`, `0xbf800000`, etc.) do not yet print characters to the serial console, despite clean code execution.
* **Next Steps:** 
  1. Identify the correct physical MMIO base address or pinmux configuration for the Nationalchip 5874 SoC UART.
  2. Implement proper UART status register checking (line status register / transmit holding register ready check) rather than blind polling.
